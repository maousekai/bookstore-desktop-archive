# bookstore-desktop-archive

Hai bản mã quản lý nhà sách JavaFX, có cả sửa đổi cục bộ chưa xuất hiện trong commit cũ. Đây là kho lưu nguồn để đối chiếu và phát triển tiếp.

Mỗi thư mục là một dự án Maven riêng, yêu cầu JDK 21 và JavaFX. Cấu hình cơ sở dữ liệu bằng biến `BOOKSTORE_DB_PASSWORD` trong bản lưu này. Các tài khoản, dữ liệu SQL, ảnh khách hàng và dữ liệu vận hành không được đưa lên. Cần chuẩn bị SQL Server/schema và kiểm tra lại cấu hình kết nối trước khi chạy.

Xem [ARCHIVE_NOTES.md](ARCHIVE_NOTES.md), [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) và [VALIDATION.md](VALIDATION.md) để biết phạm vi và kết quả kiểm tra.
